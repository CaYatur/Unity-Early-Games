# İlk Unity Oyunlarım (2021–2022)

2021–2022 · İlk Unity oyunlarım: elma/armut toplama, platform denemeleri ve Cube prototipi.

| Klasör | İçerik |
|---|---|
| `Elma-toplama-oyunu/`, `Armut-toplama-oyunu/` | Düşen meyveleri toplama oyunları; çizimler benim |
| `oyun/` | Kendi çizdiğim karakter ve zeminlerle 2D platform denemesi |
| `deneme/` | İlk Unity denemem |
| `Cube/` | Piksel karakterli küçük prototip (Ocak 2022) |

Yalnızca `Assets`, `Packages` ve `ProjectSettings` klasörleri var; `deneme` içindeki ücretsiz Asset Store paketi (BayatGames) çıkarıldı.
